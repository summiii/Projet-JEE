# Projet JEE — TP Servlet & JSP

Ce projet est un exemple simple d’application JEE utilisant :
- Une **Servlet** (HelloServlet)
- Une **page JSP** (index.jsp)
- Un **fichier web.xml** pour la configuration
- Un **projet Maven** générant un fichier WAR
- Déploiement possible via **Tomcat** ou **NetBeans**
